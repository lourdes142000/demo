Executive summary

The sample findings affect an internet-facing customer portal, an internet-reachable management page, an isolated test server, an internal printer, and a public web application. Prioritize remediation based on exposure and known exploitation—not severity scores alone.

Suggested order: B, C, A, D, then E. Finding B is being exploited in the wild; C exposes a management page that still uses a default password. A has a very high technical score, but the stated isolation and lack of data lower its immediate business priority.

Finding details

B · Authentication bypass

Priority 1

The customer portal is internet-facing, and exploitation of this issue has been observed. The activity lists CVSS 6.5.

Recommended actionApply the vendor's fix or mitigation, review relevant authentication logs for suspicious activity, and restrict exposure until remediation is verified.

Retest: Confirm the affected login path no longer bypasses authentication within the approved scope.

C · Default administrator password

Priority 2

An internet-reachable management page still uses a default administrator password. No CVSS score is provided.

Recommended actionReplace the default credential with a unique secret, limit management access to authorized networks, and review access logs.

Retest: Verify the default credential no longer works and management access is appropriately restricted.

A · Remote code execution

Priority 3

The test server has a very high technical score (CVSS 9.8), but is described as isolated and holding no data.

Recommended actionApply the relevant security update, preserve the test network isolation, and reassess if the system's exposure or role changes.

Retest: Confirm the weakness is resolved and that isolation controls remain in place.

D · Outdated TLS

Priority 4

An internal printer uses an outdated TLS configuration. The activity lists CVSS 5.3.

Recommended actionConfigure supported TLS versions and cipher suites, checking printer compatibility before deployment.

Retest: Verify that obsolete TLS options are disabled and required printing services continue to work.

E · Detailed error messages

Priority 5

A public web application returns detailed technical errors. The activity lists CVSS 3.1.

Recommended actionShow users a generic error, keep diagnostic details in access-controlled server logs, and avoid returning secrets or internal implementation data.

Retest: Confirm public responses are sanitized and useful diagnostic information remains available to authorized maintainers.

Scope, evidence, and limitations

This is a fictional learning sample, not the result of a real scan. It uses only the five findings described in the student activity. Asset identifiers, affected versions, evidence, dates, owners, and business impact details were not supplied.

Before using a real report, confirm each finding within written authorization, attach appropriate evidence, identify an owner, agree on remediation dates, and record retest results.
